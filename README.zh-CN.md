TokenFarm 是一个个人单人的氛围农场游戏，本地编程助手的 token 用量是游戏内金币的唯一
来源。使用 Claude Code 或 Codex 工作，再用产出的金币种植作物、扩建农场，并把收获转化为
经验。

游戏安静地运行在终端旁边。近期的助手活动就像阳光：你工作时作物会生长，在工作时间内长时间
不活跃后开始枯萎，而在休息时间则受到保护。

- 📜 **更新内容：** 参见[更新日志](CHANGELOG.zh-CN.md)。
- 🛠️ **配置、开发者模式与项目结构：** 参见[开发指南](DEVELOPMENT.zh-CN.md)。

## 快速开始

你需要 **Node.js 20 或更新版本**，以及至少一个本地编程助手：**Claude Code** 或
**Codex** CLI/桌面端。无需 API 密钥或账号绑定 —— TokenFarm 只读取这些助手本来就写在你
电脑上的会话日志。

```bash
git clone https://github.com/ShawnMenz/TokenFarm.git
cd TokenFarm
npm install
npm run build
npm start
```

打开 **http://localhost:8787**，选择难度和工作时间，然后回去写代码就行。助手一用 token，
金币就会到账。在 VS Code 中，**Simple Browser: Show** 命令可以把农场固定在终端旁边的
窗格里。

农场存档保存在 `~/.tokenfarm/state.json`，下次运行 `npm start` 时会从上次的进度继续。

## 游戏指南

### 游戏循环

1. 在首次启动的初始设置中选择难度与工作时间表。
2. 使用 Claude Code 或 Codex 工作，实时赚取金币。
3. 在[商店](#作物与等级)购买种子并种到田里 —— 或用 **+** 磁贴开垦新田地（每块 300
   金币，没有上限）。
4. 在晴天的工作时间内保持助手活跃，作物才会生长。
5. 收获成熟作物获得经验；移除枯萎或死亡的作物以复用田地。
6. 升级以解锁新作物、[农资](#农资)、[田地升级](#田地升级)以及替你打理农场的
   [工具](#工具与电力)。

### 金币来自 token

```text
Claude Code  ~/.claude/projects/**/*.jsonl ─┐
                                             ├─▶ TokenFarm 服务器 ──SSE──▶ 浏览器农场
Codex       ~/.codex/sessions/**/*.jsonl ────┘    tail → 金币 + 模拟
```

Token 是金币的唯一来源 —— 收获只给经验，不给金币。可计数的用量按各助手归一化：

```text
Claude Code 货币 = input_tokens
                 + cache_creation_input_tokens
                 + output_tokens

Codex 货币       = input_tokens
                 + cache_write_input_tokens
                 + output_tokens
```

Claude 的 `cache_read_input_tokens` 不计入。Codex 只读取每轮的 `last_token_usage`；
累计总量与单独的推理总量不会叠加。可计数的 token 按你的难度换算成金币：

```text
获得金币 = 可计数 token × 难度倍率 ÷ 200
```

简单为 ×1.5、普通为 ×1.0、困难为 ×0.5。小数部分保留在存档中，界面展示并花费整数金币。

只有 TokenFarm 运行期间写入的用量才算数。TokenFarm 第一次看到某个日志时，里面已有的会话
历史会被跳过；保存的读取位置保证重启后不会重复奖励。个人 Codex Cloud 任务不计入，因为它们
不提供每轮的 token 用量；本地 Codex CLI/桌面端会话可以计入。

### 天气与枯萎

- **☀️ 晴天：** 你的工作时间。助手活跃时（最近 2 分钟内用过 token），作物生长；助手闲置
  时，枯萎计时开始走。
- **🌧️ 雨天：** 非工作时间、周末，或开启了 **别卷了，我说停停**。作物受保护，既不生长也
  不衰减。

枯萎计时很宽松：晴天闲置累计约 2.5 个工作日作物才会枯萎，累计 5 个工作日才会死亡。枯萎的
作物在助手重新活跃后马上恢复，也可以用药治好。死掉的作物只能移除。在等待你无法掌控的
事情？打开 **别卷了，我说停停** 强制转为雨天。

### 额度保护

Claude Code 或 Codex 的用量额度用完时，你没法继续用它干活，这时让作物枯萎就不公平了。
TokenFarm 会从同一批本地日志里读出额度状态：

- **Codex** 每一轮都会记录一份用量快照。某个窗口用满（100%）就视为额度用完，直到该窗口
  重置。
- **Claude Code** 在用量额度用完时会写入一条错误记录。如果消息里带有重置时间就用它；否则
  保护持续 5 小时。

额度用完期间，工作时间内的闲置不会计入枯萎，天气栏会显示是哪个助手额度用完以及保护到什么
时候。如果你继续用另一个助手工作，作物照样生长。保护在重置时间结束，或者在该助手重新产生
真实用量时立即结束。

### 作物与等级

| 作物 | 金币 | 生长时间 | 收获经验 | 解锁等级 |
| --- | --- | --- | --- | --- |
| 胡萝卜 🥕 | 500 | 15 分钟 | +5 | Lv 1 |
| 小麦 🌾 | 1,500 | 30 分钟 | +10 | Lv 1 |
| 玉米 🌽 | 2,500 | 30 分钟 | +12 | Lv 3 |
| 南瓜 🎃 | 6,000 | 60 分钟 | +25 | Lv 5 |
| 苹果树 🍎 | 12,000 | 120 分钟 | +60 | Lv 8 · 需要肥沃田或更高 |

生长时间指晴天、助手活跃的工作时间。购买的种子会进入库存；种植时从库存中扣除，不会重复
收费。

经验会填满金币下方的进度条。前期每级需要 100 经验，之后逐级递增，没有等级上限。你的等级
决定商店卖什么：未解锁的卡片显示 🔒 和解锁等级，经验条下方的一行显示下一次解锁。已经拥有
的种子即使超出你的等级也照样能种。

### 农资

农资是一次性物品：买进库存，再在田里使用。

| 农资 | 金币 | 解锁等级 | 效果 |
| --- | --- | --- | --- |
| 💧 水 | 150 | Lv 2 | 被使用的作物生长加速 ×1.5。 |
| 💊 药 | 400 | Lv 2 | 治好正在枯萎的作物（死掉的救不回来）。 |
| 🧪 肥料 | 300 | Lv 3 | 被使用的作物收获时经验 ×1.5（四舍五入）。 |

水和肥料每株作物各能用一次；田里的 💧/🧪 小标记表示已经用过。有药时，正在枯萎的作物上会
出现 **💊 治疗** 按钮。

### 田地升级

下一档解锁后，空田上会出现 **⬆️** 按钮。升级是永久的，并且可以和水叠加。

| 田地等级 | 升级费用 | 解锁等级 | 生长速度 |
| --- | --- | --- | --- |
| 普通田 | — | Lv 1 | ×1.0 |
| 肥沃田 | 2,000 | Lv 3 | ×1.25 |
| 温室 | 8,000 | Lv 6 | ×1.5 |

### 工具与电力

工具只需购买一次，之后每秒自动工作，每次动作消耗 ⚡ 电。电以每包 50 ⚡、500 金币的价格
购买（Lv 4 解锁），显示在金币旁边。每个工具的商店卡片上都有 **开/关** 开关。

| 工具 | 金币 | 解锁等级 | 作用（每次动作 1 ⚡） |
| --- | --- | --- | --- |
| 🚿 洒水器 | 5,000 | Lv 4 | 给生长中的作物浇水。 |
| 🤖 收割机 | 8,000 | Lv 5 | 收获成熟作物（经验照样归你）。 |
| 🚜 播种机 | 8,000 | Lv 6 | 用你的种子库存补种空田 —— 优先种这块田上次种的作物，没有的话就种这块田能种的最贵的种子。 |

工具永远不会产出金币，所以助手的 token 仍然是金币的唯一来源。
